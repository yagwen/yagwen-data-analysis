# 概念学习资料生成 Skill

## 适用场景

当用户输入一个概念名称（如 "Agent"、"大语言模型上下文"、"Skill"），希望系统地理解这个概念、
并得到一份可保存、可复习的学习资料时，使用本 Skill。

典型触发语：
- "帮我学习一下 XX 概念"
- "我想搞懂 XX 是什么、怎么运作"
- "给 XX 生成一份学习资料"

## 输入

| 参数 | 必填 | 说明 | 默认值 |
|---|---|---|---|
| 概念名称 | 是 | 要学习的概念，如 "Agent" | 无 |
| 学习深度 | 否 | 入门 / 进阶 / 专家 | 入门 |
| 输出格式 | 否 | HTML / Markdown | HTML |

## 工作流程

1. **拆解概念**：先用自己的话写出概念的一句话定义，再拆出 3-5 个关键组成部分或机制。
2. **解释机制**：对每个组成部分给出一段通俗解释，能用生活化类比就不用术语堆砌。
3. **举应用场景**：给出 1-2 个真实、具体的应用例子（优先选择贴近学生日常的例子）。
4. **说明边界**：明确写出"学完这个概念后，我能解释什么 / 不能解释什么"，防止过度自信。
5. **概念辨析**：找出 1-2 个容易与该概念混淆的概念，说明区别。
6. **生成自测题**：出 3 道自测题（1 道定义题 + 1 道机制题 + 1 道辨析题），附标准答案。
7. **列出参考资料**：只列出真实存在、可点击核查的来源（官方文档、经典论文、知名技术博客），禁止编造 URL。

## 输出结构

生成一个独立的 HTML 文件，保存到 `learning-materials/` 目录，按概念命名（如 `agent.html`）。
页面按以下顺序组织：

1. 概念定义（一句话 + 展开说明）
2. 我的理解（第一人称，供学习者核对与改写）
3. 核心机制（分点图解或表格）
4. 应用场景
5. 学习边界（能解释 / 不能解释）
6. 概念辨析
7. 自测题（含答案，答案默认折叠）
8. 参考资料（可点击的真实链接）

## 质量自查清单

生成完成后，逐条自检，任何一条不满足都不得交付：

- [ ] 一句话定义不超过 40 字，且不使用另一个更难的术语来解释术语
- [ ] 每个机制解释单独成段，段落不超过 5 行
- [ ] 应用场景是具体的事件，不是"广泛应用于各行各业"这类空话
- [ ] 学习边界明确写出至少 1 条"不能解释什么"
- [ ] 所有参考链接均为真实可访问的来源，禁止编造
- [ ] 自测题附有标准答案

## 使用示例

```
用户：帮我学习一下 Agent 这个概念，入门深度
Skill：读取本文件 → 按工作流程生成 learning-materials/agent.html → 自查 → 交付
```
