## 定义

描述数据的两个互补维度：**集中趋势**回答"数据典型值在哪"，**离散程度**回答"数据 spread 得多开"。

## 指标清单

| 维度 | 指标 | 特点 |
|---|---|---|
| 集中趋势 | 均值 | 受极端值影响大 |
| | 中位数 | 抗干扰 |
| | 众数 | 适用于定类数据 |
| 离散程度 | 极差 | 最粗糙 |
| | 方差 | — |
| | 标准差 | 最常用 |

## 经验法则

- 数据越"离散"，均值代表性越差
- **有极端值时优先报告中位数**（已用 pandas 实验验证：把一个成绩改为 10 分，均值明显下降，中位数几乎不变）
