## 简介

Python 数据分析核心库，目前练习代码的主力工具。

## 已掌握的用法

| 操作 | 方法 |
|---|---|
| 一维数据 | `pd.Series([...])` |
| 表格数据 | `pd.DataFrame({...})` |
| 计数 | `count()` |
| 均值 / 中位数 / 众数 | `mean()` / `median()` / `mode()` |
| 标准差 | `std()` |
| 最值 | `max()` / `min()` |
| 分布统计 | `value_counts()` |
| 全景描述统计 | `describe()` |
