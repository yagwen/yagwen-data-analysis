## 问题

Agent、LLM 上下文、Skill 三者分别是什么，它们如何协同工作？

## 回答

**一句话框架：三层架构 + 一个闭环。**

### 三层架构

| 层 | 概念 | 比喻 | 关键论断 |
|---|---|---|---|
| 信息层 | [[LLM上下文]] | 办公桌上摊开的全部信息 | 上下文决定能力**上限** |
| 知识层 | [[Skill]] | 随取随用的标准手册 | Skill 沉淀**经验** |
| 执行层 | [[智能体]] | 可以自主干活的执行者 | Agent 决定**行动落地** |

更形象的比喻：**大脑**（LLM，决策核心）、**手册**（Skill，大脑的"外挂扩展"）、**双手**（Agent，大脑唯一的行动输出）。

### 一个闭环

Agent 在执行任务的过程中产生新的观察和经验 → 有价值的部分沉淀为 Skill → 下次执行时 Skill 被触发、注入上下文 → Agent 的起点更高。经验越滚越多，能力越用越强。

### 用我自己的实践验证

这套框架与我在 [[WorkBuddy]] 中的真实体验一致：
- 每次对话我能"看见"的只有当前上下文（信息层上限）；
- 我写好 concept-learning [[Skill]] 后，再说"帮我学习 XX"就不用重复解释流程（经验沉淀）；
- WorkBuddy 读资料、写文件、生成 HTML，这些自主执行就是 Agent 行为（执行层落地）。
- 本知识库本身也是这个闭环的一环：学习经验被摄入 wiki，下次会话注入上下文复用。
