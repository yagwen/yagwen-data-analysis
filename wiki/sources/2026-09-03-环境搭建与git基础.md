## 摘要

第一次搭建课程学习环境的记录：创建 GitHub 账号和公开仓库 `yagwen-data-analysis`，克隆到本地，搭好学习目录结构并完成第一次 push。

## 关键要点

- **Git 三步曲**（每天都要用）：`git add .` 暂存 → `git commit -m "修改说明"` 提交存档点 → `git push` 推送到 GitHub
- 仓库目录结构约定：notes/（笔记）、code/（练习代码）、homework/（作业）、data/（数据集）

## 关键引述

> "push 时报 `Connection was reset`：DNS 把 github.com 解析到了不通的 IP，最终用本地转发代理解决。以后遇到类似报错，先判断是不是网络问题。" —— 当天踩坑记录
