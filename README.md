# 统计与数据分析

本仓库用于《统计与数据分析》课程的学习：存放课堂笔记、练习代码、课程作业和小项目。

## 仓库结构

```
yagwen-data-analysis/
├── README.md            # 本文件：仓库说明
├── .gitignore           # Git 忽略规则（Python 临时文件等）
├── notes/               # 学习笔记（Markdown）
├── code/                # 课后练习代码（Python）
├── homework/            # 课程作业
└── data/                # 练习用数据集
```

## 使用方法

1. 平时在本地写笔记、写代码，放进对应文件夹
2. 每次学完一个小节，执行三步提交：

```bash
git add .                      # 1. 把改动加入暂存区
git commit -m "本次修改说明"    # 2. 提交到本地仓库
git push                       # 3. 推送到 GitHub
```
